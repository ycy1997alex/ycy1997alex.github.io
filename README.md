# Alex Yu Personal Website

This repository contains the generated static files for Alex Yu's personal website, published as a GitHub Pages style site.

## Website Content

The site includes:

- Home page: personal landing page with avatar and social links.
- About: personal background, education, skills, and experience.
- Posts: blog posts and interactive checklist pages.
- Projects: project and research experience.
- Contact: contact information.
- Tags, categories, authors, and series archive pages.
- English and Traditional Chinese page trees.

Recent interactive pages added under `posts/`:

- `posts/travel-checklist/index.html`: travel preparation checklist.
- `posts/call-up-list/index.html`: military call-up packing checklist.

Both checklist pages are standalone HTML pages wrapped in the same Coder/Hugo-style site layout, including navigation, footer, dark-mode toggle, and local checkbox state saved in `localStorage`.

## Generated Static Site Notes

The HTML structure looks like it was generated by Hugo using the Coder theme. Because this folder contains generated output, manual edits must be repeated in several places when adding a new post.

When adding a new post manually, check at least:

- New page folder under `posts/<slug>/index.html`.
- `posts/index.html`.
- `zh-tw/posts/index.html`, if the post should appear in the Chinese listing.
- `index.xml` and `posts/index.xml`.
- `zh-tw/index.xml` and `zh-tw/posts/index.xml`, if included in the Chinese feed.
- `en/sitemap.xml` or the relevant sitemap.
- `change.log`.

## Maintenance Recommendation

For long-term maintenance, it would be easier to keep the Hugo source project and regenerate these files from content files and templates. See `Discussion.md` for a fuller discussion.
