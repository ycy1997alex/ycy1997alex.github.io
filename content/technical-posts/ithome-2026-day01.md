## 我想搞清楚的事

Claude 有三個入口：claude.ai（網頁版與 App 版共用，跑在雲上）、Claude Desktop（只能在本機用，碰得到電腦裡的 Word、Excel、PPT，甚至有人拿它診斷電腦效能）、Claude Code（在 Command Window 或 VS Code 裡跑，讀得到整個專案、改得了檔案、下得了指令，基本上當作另一個自己也沒有問題 (?)）。

同一個模型，三種用法。那到底哪件事該開哪一個？

這 30 天就是我拿幾個真實專案，從航太模擬一路做到藍牙手環和股票評分系統，去回答這個問題的過程。

免費版時期的 Claude，我覺得他誠實、正直、很少廢話（訂閱之後才發現他腦內小迴圈其實不少）。文件改寫、翻譯、程式碼架構生成這類輕量任務，免費版能用到 Sonnet 等級就已經很夠看。後來能用 Opus 等級，我開始把過去那些一直 Pending 的事情重新翻出來。

## 這 30 天要回答的三個問題

> **這三個介面，該怎麼分工？**

> **用了 Claude 之後，我的工作流程會變成怎樣？**

> **在不同領域裡，是不是都能靠 Claude 更容易理解某些構念、或完成某些任務？**

我心裡當然有個直覺的答案：claude.ai 做一次性探索，Claude Desktop 處理文件雜事，Claude Code 負責程式專案。聽起來很合理，合理到有點像廢話。

但我真正想知道的是另一件事：**會不會做到最後，全部收斂到 Claude Code 就好了？**

明天 Day 02 會從三個介面的記憶機制講起，把這個猜想推成一個講得出理由、也講得出驗收條件的假說，然後留到 Day 30 來打臉。

## 我的背景，以及為什麼這件事對我來說很麻煩

我大學讀航空太空工程學系，雙主修心理學，碩士讀腦科學，職涯上跟醫療器材研發脫不了關係，工作項目多半在跟生理訊號搏鬥。

這個組合聽起來很跳，實際工作起來更跳。同一週裡我可能要處理光學訊號的雜訊分解、研究寫深度學習模型、整理臨床資料、跑統計分析、把模型打包成 Docker API 交付、寫報告、補中英雙語技術文件。~~然後發現前面資料給錯，模型重跑，圖表重放。~~

問題就出在這：**每一個情境我對 AI 的要求都不一樣。**

做訊號處理的時候，我要知道它哪些地方用了近似、誤差多大。寫臨床報告的時候，一個數字都不准編造。做前端展示的時候，我只希望它不要生出一個會動但字體疊來疊去的超醜 UI。

如果每次都要重新交代一遍，那 AI 只是個比較會講話的搜尋引擎。我想確認的是：**把這些規範沉澱成檔案、複用幾十次之後，到底能達成什麼效果？**

所以這系列不會只是「用 Claude 做了什麼」，而是「怎麼讓 Claude 每次都照某個規矩做事」。

## 這 30 天長什麼樣

我刻意讓題目橫跨背景裡的每一塊。跨得夠開，才知道這套規範是不是真的通用。

| 階段 | 在做什麼 |
|---|---|
| 基礎說明 | 三介面的記憶機制差異、提示詞優化 |
| 提示詞 | 讓 Claude 幫我寫給別的模型用的提示詞 |
| 實作挑戰 | HTML 模擬：航太、心理、腦科學，各選一個任務實測 |
| 基礎建設 | CLAUDE.md / Agents & Rules & Skills / Sessions |
| Office 應用 | Word / PPT / Excel 的實際操作與能力邊界 |
| Python MVP | 軟體架構應用、做自己的需求小程式 |
| 網路與硬體 | WiFi 調校、藍牙手環串接 |
| 個人網頁 | 從文件到網頁、網頁重構測試 |
| 股票軟體開發整合 | MVP、總體經濟與個股評分系統、資料庫、自動化打包、部署 |
| 總結 | 學到什麼、驗收 |

另外先提醒一句：股票軟體開發整合會使用到永豐金 Shioaji 和 FRED 等 API。而 Shioaji 有審核時程，想跟著做的人，現在就可以去辦了。

## 能從這裡帶走什麼

**一整套可以直接抄的規範。** 不只是全域 CLAUDE.md，還包含專案級 CLAUDE.md、Rules、Agents、Skills、Session 交接信怎麼分層。每一條規則我都會講它是為了擋掉什麼問題才長出來的。不用照抄，但至少知道從哪裡開始寫自己的。

**一組介面分工的判斷依據。** 下次要做一件事的時候，能比較快決定該開哪一個。

**失敗的過程。** 我會把坑如實寫出來。踩過的坑寫進規則之後才有價值，而且全部都寫成功的~~也沒人要看~~，大概也學不到什麼。

## 幾件先講清楚的事

股票內容是技術示範，講的是資料擷取、評分邏輯與自動化部署怎麼實作，不是投資建議，也不會有任何績效宣稱。

這 30 天想確認的是：Claude 進到我的工作流程之後，規範有了，還「多」出了什麼。

明天先從最基礎的開始：這三個介面各自記得住什麼、忘掉什麼，以及跨介面協作到底可不可行。
