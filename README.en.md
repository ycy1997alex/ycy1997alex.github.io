# Alex Yu — Personal Website

[繁體中文](README.md) ｜ **English**

Source for my bilingual (English / 繁體中文) personal website, live at
**<https://ycy1997alex.github.io>**.

Built with [Hugo](https://gohugo.io/) and the
[hugo-coder](https://github.com/luizdepra/hugo-coder) theme, and deployed
automatically to GitHub Pages.

## What's on the site

- **About** — background, education, skills, and publications
- **Projects** — research and engineering projects
- **Blog** — posts and interactive tools
- **Contact**

Every page is available in **English** and **Traditional Chinese**, switchable
from the navigation bar.

## How it's built

| | |
|---|---|
| Static site generator | Hugo (extended) |
| Theme | hugo-coder |
| Hosting | GitHub Pages |
| Deployment | GitHub Actions — auto-build on push to `main` |
| Analytics | Google Analytics 4 |

This repository contains the Hugo **source** — Markdown content plus the theme.
The published HTML is generated by Hugo at deploy time and served from GitHub
Pages; it is not committed here.
